# 코드 작업 워크플로우

ui·api 모두 코드 작업은 아래 순서로 진행한다.

1. **확인**: 관련 기존 코드와 컨벤션을 먼저 읽고, 재사용할 코드를 찾는다.
2. **작성**: 컨벤션에 맞게 코드를 작성한다.
3. **검증**: 테스트·빌드·실행으로 변경한 동작을 확인한다.
4. **재검토**: 아래 관점으로 변경 코드를 다시 보고, 개선사항이 없을 때까지 수정 → 3번을 반복한다.
   - 컨벤션 준수
   - 중복·재사용 가능한 기존 코드
   - 단순성(불필요한 추상화·파일·래핑)
   - 버그·엣지 케이스·오류 처리
   - 보안·성능
   - 네이밍·주석
5. **문서 현행화**: 새로 정한 규칙이나 문서에 반영할 변경이 있으면 사용자에게 "마크다운에 반영할까요?"라고 묻고, 승인받은 뒤 반영한다. 대상 문서는 `duous-doc/README.md`의 문서 목록을 따른다.
6. **보고**: 변경 내용, 검증 결과, 재검토에서 고친 점을 짧게 알린다.
